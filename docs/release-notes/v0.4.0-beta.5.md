# dsh-session-grove 0.4.0-beta.5

First language batch after Japanese.

## Added

- Complete Korean, German, French, Spanish and Brazilian Portuguese dictionaries (`locale/ko.json`, `de.json`, `fr.json`, `es.json`, `pt.json`), 288 keys each.
- Matching plugin manifest titles and descriptions for all five languages.
- Eight packaged languages now share one registry: `en`, `zh`, `ja`, `ko`, `de`, `fr`, `es`, `pt`.
- Regional ids resolve to their base language (`ko-KR` → `ko`, `de-AT` → `de`, `pt-BR` → `pt`, etc.).

## Verification

- 482/482 unit and contract tests.
- Every dictionary checked for identical keys, placeholder sets and non-empty values.
- English and official/community A+ suites remain green.

## Known limits

- Count strings do not have plural variants yet.
- RTL languages are not supported yet.
- A third-party language-pack A+ fixture is still pending.
