# dsh-session-grove 0.4.0-beta.45

Dead-export cleanup and a static export-usage guard.

## Removed

- Retired 27 dead exports (16 planned, one cascading session helper, nine
guard-discovered, and `groupColorValue` after fixing comment-blind counting) from the shared model, core
  tree/filter/virtual-list/drag/control modules, client icons and the DSH
  selector; the assertions that still had value now go through production
  paths (`buildRenderTree`, `statusSectionsByGroup`, `resolveGroupDrop`,
  `applyControlOperations`, `computeVirtualWindow`, `HEADER_ICON_ARTWORK`,
  `selectDshAdapter`).
- Added `tests/core/export-usage.test.js`: scans every
  `export const|let|var|function|class` declaration under `src/`, counts
  references outside the defining file and inside it, and fails with a
  `file:name` list when both counts are zero. Only the Cordis dynamic entry
  names in `src/index.js` (`Config`/`apply`/`inject`/`name`) are allowlisted.
- The new guard also exposed nine fully-dead declarations (`__internal`,
  `dropTargetKey`, `resetDiagnosticsForTests`, `ICON_NAMES`, `VIEW_MODES`,
  `DROP_KINDS`, `previewDrop`, `workspaceFor`, `siblingGroupIds`, plus
  `groupColorValue`); they were removed as part of making the guard pass.
  No runtime path references them. The guard now strips comments before
  counting references and explicitly allowlists both Cordis entries.

## Documentation

- Removed the `removeSession` row from the frozen shared-model contract list.
- Version `.45` across package, manifest, constants, lockfile and the current
  docs; rebuilt `lib/client.js` plus 17 lazy locale chunks.
- Test suite: 513 tests; coverage measured at 92.3% lines / 82.9% branches / 89.1% functions (repeated Node coverage runs vary by about ±0.05).
- No runtime, UI, host/HTTP protocol or dependency change.

This candidate has not been tagged or released.
