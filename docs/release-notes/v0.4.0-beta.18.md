# dsh-session-grove 0.4.0-beta.18

Arabic language plus RTL foundation.

## Added

- Complete Arabic dictionary `locale/ar.json` (287 keys) with CLDR
  `zero/one/two/few/many/other` plural objects and Arabic manifest title.
- `src/client/i18n/direction.js`: base-language RTL detection plus
  `Intl.Locale#textInfo` probe.
- Plugin root `dir="rtl"` driven by the active locale.
- Core RTL CSS overrides for the header/status actions, group indent guides,
  row counts/times, session overflow, scroll rail and config sub-panels.
- All-locale injection now includes Arabic and asserts `dir` (23 cases total).

## Verification

- 493/493 unit and contract tests.
- All-locale injection: Arabic header + new-group dialog + `dir="rtl"` PASS.
- English A+ remains the full-surface runtime gate; existing Japanese fixture
  remains limited to onboarding/new-group dialog.

## Known limits

- This is an RTL foundation, not a complete visual mirror audit. Menu/dialog
  geometry, the resize handle and fine-grained icon direction still need a
  dedicated RTL visual pass.
- Arabic zero/one plural surfaces share the same `{n}` string because
  placeholder parity is enforced for every plural category.
