# dsh-session-grove 0.4.0-beta.4

First packaged language after the localization foundation.

## Added

- Complete Japanese dictionary: `locale/ja.json`, 288 keys.
- Japanese plugin manifest title (`フリーグループ`) and description.
- All locale dictionaries are registered with the host locale service; the plugin still does not call `addLanguage`, so the host or a third-party language pack remains the owner of the language catalog.
- `ja`, `ja-JP` and other base variants resolve to Japanese. Unsupported languages fall back to English.

## Verification

- 481/481 unit and contract tests.
- All dictionaries checked for identical keys, placeholder sets and non-empty values.
- No tag, GitHub Release or market PR has been created for this version yet.
