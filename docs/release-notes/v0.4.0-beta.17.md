# dsh-session-grove 0.4.0-beta.17

All-locale injection test harness (no plugin runtime behavior change).

## Added

- The test-only locale pack now registers every packaged language, including
  `zh-Hant`, `zh-TW`, `zh-HK`, `zh-MO`, `zh-CN`, `zh-SG` and `pt-BR`.
- Exposed a test-only locale switch hook and active-snapshot getter.
- Added `e2e/all-locales.spec.mjs`: 22 cases assert the header and the
  new-group dialog after switching the host locale through the pack.

## Result

Each language/alias renders its own header title and `dialog.newGroup` copy.
The test waits for the active host locale and for the dialog title to settle,
so it measures the final locale state rather than a transient render.
