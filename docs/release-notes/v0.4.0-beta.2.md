# dsh-session-grove 0.4.0-beta.2

Hotfix for the identity-reset beta. The display title remains **Free Groups / 自由分组**.

## Fixed

- English hosts could render plugin-owned onboarding, settings, context menus and dialogs in Chinese when the native official desktop shell did not expose the community locale translator.
- Locale resolution now uses, in order: the Host locale snapshot, the document `<html lang>`, the browser language. Chinese remains only the last fallback when no signal exists.
- The packaged English dictionary was already complete; this was a locale-resolution bug, not a missing-string bug.

## Verification

- 479/479 unit and contract tests.
- Coverage: 93.67% lines / 82.42% branches / 88.94% functions.
- Community and official isolated A+ suites: PASS.
- Isolated A+ now asserts English onboarding, group-menu, dialog-title and settings copy.
