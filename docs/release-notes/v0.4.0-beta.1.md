# dsh-session-grove 0.4.0-beta.1

Identity-reset release for DSH Desktop. The display title remains **Free Groups / 自由分组**.

## Highlights

### New identity

- Package and plugin/bundle id: `dsh-session-grove`.
- Host routes: `/dsh-session-grove/*`.
- Record, control token, diagnostics and debug files: `dsh-session-grove.*`.
- Client localStorage namespaces: `dsh-session-grove.*`.
- Native tool: `session_grove_control`; managed skill/CLI: `session-grove-control`.

### Manual migration only

The old `dsh-session-groups` record and browser preferences are intentionally
**not read, copied or deleted**. The old package name is shared with unrelated
community plugins, so silent migration could import another plugin's data.

See `docs/MIGRATION-0.4.md` for the manual checklist. Remove the old plugin
before installing the new package; do not run both identities in one profile.

### Control surface

- Read-only `catalog` with icon/color/format/operation vocabulary.
- Strict `invalid-icon` / `invalid-color` validation for control writes.
- Session reorder actions remain available.

## Compatibility
