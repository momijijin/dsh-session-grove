# dsh-session-grove 0.4.0-beta.12

Subagent-status plural completeness.

## Changed

- Replaced the flat `status.subagentsRunning.one` / `.other` translation keys with a single plural object `status.subagentsRunning`.
- `subagentStatus()` now emits one stable label key and always passes `{n}`.
- Polish now renders one/few/many/other forms; other languages keep one/other.

## Verification

- 486/486 unit and contract tests.
- All dictionaries still share the same key set, with plural categories allowed to differ by language.
- Regular isolated A+ fixtures remain available.

## Known limits

- `dialog.deleteMoveBody` still has two independent counts and remains a string.
- RTL languages are still pending.
