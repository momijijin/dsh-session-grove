# dsh-session-groups 0.3.0-beta.73

Stable beta release for DSH Desktop, built from the main-branch release boundary.

## Highlights

### Groups and sessions

- Group context menu now starts with **New session**. It reuses the group row's first `+` action, including workspace inference, choice dialog and failure handling.
- Added `group.newSession` in English and Chinese.
- The existing explanatory `group.addSession` tooltip remains unchanged.

### Accessibility

- Dialogs have an accessible title, initial focus, opener-focus restoration, a Tab/Shift+Tab focus trap and Escape handling for every dialog kind.
- The dialog titlebar moves with the arrow keys; the bottom-right resizer resizes with the arrow keys. Shift uses a 1px step.
- The group menu supports ArrowUp/ArrowDown/Home/End roving focus and returns focus to the originating row.

### Reliability and maintainability

- Store writes use an in-process queue plus a short-lived cross-process lock; stale locks are reclaimed after the owner PID disappears or the lock is 30 seconds old.
- `controlSessions` now requires `controlApi`; the settings UI disables and visually nests the dependent switch.
- `components.js` was reduced from 3051 to 1366 lines through focused component modules.
- `routes.js` was reduced from 1040 to 520 lines through `route-contract.js` and `control-routes.js`.

### Performance

- The running spinner rotates only its outer transform; the SVG arc is static and no longer repainted every frame.
- The session subscription is narrowed to main sessions plus the currently retained subagent.
- Ungrouped-list layout is measured on mount/resize; scroll frames no longer force `getBoundingClientRect`.

## Compatibility

- DSH Desktop 2.0.18 / `@deepseek-ai/dsh` 0.2.1-rc.2.
- Windows desktop UI: verified locally by the maintainer.
- Linux/macOS: Node 24 CI matrix passes (tests, build, pack, coverage gate on Ubuntu); real DSH UI remains experimental on those platforms.

## Verification

- Coverage: 93.63% lines / 82.24% branches / 88.73% functions (`src/**`).
- Isolated A+ suite PASS.
