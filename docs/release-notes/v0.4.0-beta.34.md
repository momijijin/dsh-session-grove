# dsh-session-grove 0.4.0-beta.34

Cohesion cleanup after the split series.

## Changed

- Renamed `groups-view-data` to `groups-view-state`; it is now a data-only
  adapter again.
- Moved the stable handler proxy back into the GroupsView event layer.
- Split the broad menu/action surface into:
  - `groups-view-menu-handlers.js` (79 lines): menu anchors/context/navigation
  - `groups-view-dialog-handlers.js` (94 lines): dialog/move/archive/fork commands
- Each factory now takes a narrower context; duplicated imports removed.
