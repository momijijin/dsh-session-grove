# dsh-session-grove 0.4.0-beta.7

Test-only proof that the plugin follows a third-party language pack.

## Added

- `e2e/fixtures/ja-locale-pack`: a disposable DSH client bundle that calls the
  host locale service's `addLanguage({ id: 'ja', fallback: 'en' })` and
  `setLocale('ja')`.
- `e2e/locale-pack.spec.mjs`: an isolated Playwright gate asserting Japanese
  onboarding and new-group dialog copy after the pack activates.
- `scripts/qa/start-isolated-web.ps1 -LocalePack <path>`: optional second plugin
  installation for language-pack fixtures.

## Verification

- 484/484 unit and contract tests.
- Third-party ja locale-pack A+ PASS.
- Regular community/official A+ suites remain green.

## Notes

- The fixture is test-only; it is not included in the published package files.
- The plugin still does not add languages to the host catalog itself.
