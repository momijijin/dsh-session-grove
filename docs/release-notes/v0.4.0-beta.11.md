# dsh-session-grove 0.4.0-beta.11

Polish and Turkish language support.

## Added

- Complete Polish and Dutch dictionaries? No — this version adds **Polish** and **Turkish**:
  - `locale/pl.json` (288 keys) with `one/few/many/other` plural categories.
  - `locale/tr.json` (288 keys) with invariant `one/other` forms after numerals.
- Manifest titles/descriptions:
  - Polish: **Wolne grupy**
  - Turkish: **Serbest Gruplar**
- Twelve packaged languages: `en zh ja ko de fr es pt it nl pl tr`.

## Verification

- 486/486 unit and contract tests.
- Polish plural selection is covered with real `Intl.PluralRules('pl')` categories.
- All-dictionary parity accepts language-specific plural category sets while requiring `other` and placeholder parity.

## Known limits

- `dialog.deleteMoveBody` still has two independent counts and remains a string.
- RTL languages are still pending.

No tag, GitHub Release or market PR has been created for this version yet.
