# dsh-session-grove 0.4.0-beta.60

Multiple named group profiles plus a readable profile switch preview.

## Added

- Named group configurations (profiles): a header chevron opens a profile
  popover with the active profile, per-profile counts, save-as and manage
  entries.
- Switching profiles first shows a read-only difference preview (groups
  added/removed/renamed/moved/reordered; sessions moved/newly grouped/
  ungrouped/stale); identical configurations switch directly without a dialog.
- Save-as, rename, archive and manage dialogs, a 20-unarchived-profile limit and
  a 5-second undo action on the switch toast.
- The active profile is global: every window follows the same profile through
  SSE `active` events, and committing to a profile that is no longer active
  returns 409 `profile-changed`.
- Profile-scoped collapsed state and an epoch-based reset of the document,
  revision, optimistic queue and view interactions on every switch.
- Recovery: the active named profile is probed read-only at `/load`; a corrupt,
  invalid or missing document returns `409 profile-unhealthy` /
  `profile-missing` without quarantining, restoring a `.bak` or writing an empty
  document, and the UI shows a recovery strip that can switch to a healthy
  profile. Archived profiles keep their document, backups and sessions (a
  restore UI is not implemented; un-archiving requires editing the registry
  entry).
- Storage: `dsh-session-grove.profiles.json` registry plus one directory per
  named profile (`storages/profiles/<id>/`), each with its own
  `.bak`/`.lock`/quarantine family. The default record stays at
  `storages/dsh-session-grove.json`, `DOC_VERSION` stays 1, and no data is
  migrated.
- AI control: `profileId` is optional for `state`/`resolve` (defaults to the
  active profile) and required for `plan`/`apply` when several profiles exist;
  `planHash` is bound to the profile; HTTP idempotency keys are scoped as
  `${profileId}:${idempotencyKey}`; there is no activate/switch action; `doctor`
  reports the registry and per-profile health.
- i18n: 45 `profiles.*` keys in all 19 dictionaries (331 keys total).

## Fixed

- Profile switch preview layout: two-level hierarchy (group title plus indented
  `from → to` lines), `+`/`−`/`~` group markers and section/block/list
  dividers; the preview body scrolls internally (min 320 / max 560, width 560)
  so long diffs no longer break the dialog.
