# dsh-session-grove 0.4.0-beta.24

Architecture-guard hardening and locale-safe absolute time.

## Changed

- Dependency guard now scans:
  - static `from` imports
  - side-effect imports
  - dynamic `import()`
  - `require()`
  - unresolved relative imports
  - root → client composition-root imports
- Core/shared boundary guards recurse nested directories and reject Intl /
  locale-sensitive formatting and Node builtins.
- The i18n UI boundary now scans every client module except the i18n
  implementation and `locale.js` facade (includes `dialog-host.js`,
  `plugin.js`, menus and settings).
- `plugin.js` now uses the locale facade for direction instead of importing
  `i18n/direction.js` directly.
- Absolute timestamp formatting moved from `client/time.js` to
  `client/i18n/date-format.js`; UI reads it through the runtime bridge.
- Added recursive/guard tests and a full-client i18n scan.

- No storage/manifest behavior change.
