# dsh-session-grove 0.4.0-beta.14

Behavior-preserving i18n layering refactor.

## Changed

- Split `src/client/locale.js` into:
  - `i18n/resources.js` — locale JSON + dictionary registry
  - `i18n/locale-id.js` — normalization and host/environment resolution
  - `i18n/message-format.js` — CLDR plural selection + interpolation
  - `i18n/translator.js` — dictionary selection + `createTranslator`
- `src/client/locale.js` is now a thin re-export facade, so existing imports
  continue to work.
- Added `tests/client/i18n-architecture.test.js`:
  - UI components do not import locale JSON / i18n internals / `Intl.PluralRules`
  - `src/core` does not select plural categories
  - only the resources module imports locale JSON
  - the facade remains thin

## Verification

- 490/490 unit and contract tests.
- Build succeeds.
- No runtime behavior, locale resource, manifest or storage change.
