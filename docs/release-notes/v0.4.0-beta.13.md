# dsh-session-grove 0.4.0-beta.13

Vietnamese, Thai and Indonesian language support.

## Added

- Complete Vietnamese, Thai and Indonesian dictionaries:
  - `locale/vi.json` — **Nhóm tự do**
  - `locale/th.json` — **กลุ่มอิสระ**
  - `locale/id.json` — **Grup Bebas**
- 287 top-level keys each, preserving one/other plural objects even where the
  language does not mark plural after numerals.
- Fifteen packaged languages: `en zh ja ko de fr es pt it nl pl tr vi th id`.

## Verification

- 486/486 unit and contract tests.
- All dictionaries pass key/plural/placeholder/non-empty parity.
- Community A+ remains available; no runtime code changed beyond locale data.

## Notes

- The authoritative top-level dictionary key count is **287** (295 leaves once
  `meta.title`/`meta.description` are expanded). Older docs saying 288 were off
  by one.
