# dsh-session-groups 0.3.0-beta.76

Release candidate for DSH Desktop. Prepared from the local integration branch; no tag has been created yet.

## Highlights

### Official desktop compatibility

- Verified against the official **DeepSeek Harness desktop 0.2.1.0** bundle and DSH core **0.2.1-rc.5** in an isolated runtime.
- Session creation now prefers `sessions.create` / `uiWorkspace.sessions.create` when the host exposes it, so a group's **New session** action does not reuse a blank already placed in another group.
- The community rc.2 path (`startSession` + snapshot diff + `connectWorkspace` fallback) remains intact and was rerun against **community DSH Desktop Stable 2.0.18 / DSH 0.2.1-rc.2**.

### Session ordering

- Session context menu now has **Move up** / **Move down**, aligned with the group context menu.
- Moves are persisted within the current group or explicit ungrouped list; edge actions are disabled.
- Added `session.moveUp` / `session.moveDown` in English and Chinese.

### Metadata and CI

- English title normalized to **Free Groups**; onboarding uses **Welcome to Free Groups**.
- Added the package-root icon and included `assets/icon-180.png` in the npm tarball, so DSH plugin manager renders the real icon.
- GitHub Actions updated to `checkout@v5` / `setup-node@v5`; Ubuntu runner pinned to `ubuntu-24.04`.

## Compatibility

- **community DSH Desktop Stable 2.0.18** / `@deepseek-ai/dsh` 0.2.1-rc.2: verified.
- **official DeepSeek Harness desktop 0.2.1.0** / `@deepseek-ai/dsh` 0.2.1-rc.5: verified at the official bundle's DSH host/core level with an isolated web profile; the full official desktop-window profile composition remains a manual confirmation.
- **community DSH Desktop Beta** and **community DSH NEXT (`-next`)**: not officially supported, no compatibility promise.
- `engines.dsh`: `>=0.2.0-rc.2 <0.3.0`.
