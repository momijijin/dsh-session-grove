# dsh-session-grove 0.4.0-beta.6

Localization plural foundation.

## Added

- `formatMessage` accepts per-category plural objects and selects a category with `Intl.PluralRules`, using the resolved locale id.
- Migrated `group.sessionCount` and `sessions.expand` to `one`/`other` templates in all eight packaged languages.
- Missing count params fall back to the `other` template; malformed/unsupported locales use the English plural rules.

## Verification

- 484/484 unit and contract tests.
- Community and official isolated A+ suites remain green.
- Aggregate locale validation now understands plural objects and checks category sets, per-category placeholders and non-empty values.

## Known limits

- Other count strings (`time.*`, `dialog.deleteMoveBody`) still need plural templates.
- RTL languages and a third-party language-pack A+ fixture are still pending.
