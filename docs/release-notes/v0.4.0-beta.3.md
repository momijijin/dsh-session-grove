# dsh-session-grove 0.4.0-beta.3

Localization foundation for future language packs.

## Highlights

- Locale IDs normalize to their base language: `ja-JP` → `ja`, `zh-Hant` → `zh`, `en-US` → `en`.
- Packaged dictionaries live in one registry and are selected by base language.
- Unknown or unsupported locales fall back to **English**, never silently to Chinese.
- Every bundled dictionary is registered with the host locale service. The plugin does not call `addLanguage` and does not own the host language catalog; a third-party language pack can activate a language later without changing plugin code.
- Host snapshot → `<html lang>` → navigator remains the locale resolution chain.
