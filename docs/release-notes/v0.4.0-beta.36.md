# dsh-session-grove 0.4.0-beta.36

Lazy locale chunks.

## Changed

- Main client bundle now contains only the English fallback and Simplified
  Chinese dictionaries.
- The other 17 dictionaries are generated as package-local
  `lib/client.locale-<language>.js` chunks at build time.
- `resources-lazy.js` loads a chunk through the host
  `require.async('./client.locale-<language>.js')` transport.
- The locale runtime registers the loaded dictionary, updates the translator
  registry and dispatches `locale-changed`.
- Main bundle: ~421 KB raw / ~98 KB gzip (from ~707 KB raw / ~189 KB gzip).
  All 17 chunks total ~354 KB and are loaded on demand.

## Verification

- 500/500 unit and contract tests.
- all-locales 23/23 PASS against lazy chunks (including pl, ar/RTL, settings).
- English community A+ PASS.
- Build PASS; all locale chunks included in the package.
