# dsh-session-grove 0.4.0-beta.20

Expanded non-English surface smoke and narrow visual checks.

## Changed

- `test:all-locales` now asserts, for all 23 cases:
  - header title
  - new-group dialog title, placeholder, cancel and confirm
  - group-menu new-session/new-subgroup/rename/color/delete labels
  - Arabic root `dir="rtl"`
- Session rows now include `store.localeRevision` in their memo comparator, so
  localized blank/workspace/time labels repaint immediately after a locale
  switch.
- Narrow mode hides zero-count status numbers to preserve header-title width.
- Visual evidence: ru/hi/ar screenshots at a 252px plugin root, with a
  no-horizontal-root-overflow assertion.

## Verification

- 493/493 unit and contract tests.
- All-locale smoke: 23/23 PASS (header + dialog + group menu; Arabic RTL).
- English 1280px A+ remains the full-surface runtime gate.

## Known limits

- Settings/config is still not part of the all-locale smoke.
- Header titles ellipsize at the 252px minimum (full text remains in the
  tooltip); full Arabic RTL visual mirror is still deferred.
