# dsh-session-groups 0.3.0-beta.68

Beta release for DSH Desktop.

## Fixes

- External AI/HTTP commits now refresh the groups tree in the background. The current tree stays mounted instead of showing the loading placeholder for a frame; a background failure keeps the tree and reports a banner.
- The settings-page info icon now uses a transparent background, letting the host surface show through.

## Compatibility

- Runtime is platform-neutral JavaScript; no PowerShell dependency.
- Windows UI: verified locally.
- Linux: Node/unit tests, build and package verified by GitHub Actions.
- macOS: not yet verified.
- The Ubuntu CI is a Node-level gate, not a cross-platform UI certification.

## Verification

- 446/446 unit and contract tests.
- Coverage gate, client bundle build and `npm pack --dry-run` pass on Ubuntu Node 24.
- Real desktop UI was tested by the maintainer on Windows.

## Install

Ordinary users should install through **dshmarket** after the catalog listing is published; search for `dsh-session-groups`.

The attached tarball is the maintainer/developer install artifact. Existing local-tarball installs are not market-bound and should be reinstalled from the market once the listing exists.

## Notes

This is a prerelease. The release workflow only runs for `v*` tags and does not run on ordinary branch pushes.
