# dsh-session-grove 0.4.0-beta.46

Release gate hardening.

## Changed

- Release workflow now runs `npm run check:coverage` and `npm run check:release`,
  generates `SHA256SUMS`, uploads it with the tarball, and only applies
  `--prerelease` to tags with a prerelease suffix.
- Added `scripts/qa/check-release.mjs`: zero-dependency preflight for the four
  version sources, tag/version equality when `GITHUB_REF_NAME` is set, current
  release note, `lib/client.js` version stamp and packaged paths.
- Added 9 release-preflight tests (522 total).
- A+ / all-locales remain manual local evidence; the release workflow does not
  start an isolated host or fake those results.
