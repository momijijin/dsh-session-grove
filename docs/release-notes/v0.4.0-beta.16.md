# dsh-session-grove 0.4.0-beta.16

Traditional Chinese support with script-aware resolution.

## Added

- Complete Traditional Chinese dictionary: `locale/zh-Hant.json` (287 keys).
- Manifest title/description for `zh-Hant`.
- Script/region-aware locale candidates:
  - `zh-Hant`, `zh-TW`, `zh-HK`, `zh-MO`, `zh-Hant-TW` → Traditional `zh-Hant`
  - `zh`, `zh-CN`, `zh-Hans`, `zh-SG` → Simplified `zh`
- The resolver uses explicit script, `Intl.Locale` maximization and a small
  region-script fallback table; it is covered by alias tests.

## Verification

- 491/491 unit and contract tests.
- `Intl.PluralRules` continues to use the original locale id for plural
  selection.
- English A+ and the Japanese language-pack fixture remain the runtime gates;
  Traditional Chinese is unit-tested only until a language pack/real shell run
  exists.
