# dsh-session-grove 0.4.0-beta.63

First-run guidance as a funnel instead of a bundled tour layer, plus four
one-line in-place hints. Unreleased `dev` batch — the latest published release
is `0.4.0-beta.62`.

## Entry hint

- The workspace-header toggle now carries a one-time dot badge and a small
  anchored coach mark (plain DOM, like the toggle itself). It explains the
  non-destructive layer before the user has ever opened the groups view — the
  only place a plugin can legitimately appear at "first launch", because the
  host exposes no first-run slot.
- Dismissal is persisted under the new key
  `dsh-session-grove.entry.v1`; entering the view through the toggle or the
  hint's primary action also retires it. A dismissed hint installs neither the
  dot nor the bubble. The hint anchors to the plugin's own fixed button, never
  to host DOM nodes, and clamps to the viewport (RTL included).
- `getHint` is read once per workspace-mode install; the copy is resolved from
  the active locale at that moment.

## Onboarding card

- The one-time card is now action-first: one sentence about the layer, then
  **new group**, **full guide** (external README link) and **dismiss**. The
  long-form reference stays in the repository README; the package bundles no
  onboarding prose beyond the localized one-liners.
- The card is the genuine empty state: when the tree is truly empty it replaces
  the plain empty state, and when data exists it stays a compact note at the
  top. Archive-filter empty states keep their own copy and actions.
- The docs link resolves to `README.zh.md` for `zh*` hosts and `README.md`
  otherwise, through `DOCS_BASE_URL`; the runtime bridge now exposes the
  resolved locale id.

## In-place hints

- View options: one muted line under the two archive tri-states explains that
  filters only change what is shown and that archiving a group locks its
  structure without archiving its sessions.
- Status popovers: one line notes that running / waiting / unread are
  exclusive and exclude background jobs.
- Session menu: the fork row carries a `title` describing the fork point and
  child placement; a locked row keeps its disabled reason instead.
- Group menu: the archive row carries a `title` describing the structure lock
  and the fact that sessions stay open; locked rows keep their own reason.

## i18n and compatibility

- 385 → 394 keys in all 19 dictionaries. Nine keys are new
  (`entry.title/body/primary/dismiss`, `onboarding.docs`, `archive.hint`,
  `group.archiveHint`, `status.hint`, `session.forkHint`); `onboarding.title`
  and `onboarding.body` are rewritten shorter in every dictionary. Structural
  parity remains enforced by `npm test`.
- No document schema change: `DOC_VERSION` stays 1, no new fields, no
  migration. Only one new browser-local preference key.
- The new copy is covered by unit tests (persistence, workspace toggle, chrome
  wiring), UI runtime cases (card docs link, view-options hint) and the
  isolated A+ regression (entry hint → groups view, onboarding dismissal,
  reload persistence).
