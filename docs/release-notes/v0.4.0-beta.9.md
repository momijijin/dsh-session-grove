# dsh-session-grove 0.4.0-beta.9

Italian and Dutch language support.

## Added

- Complete Italian and Dutch dictionaries (`locale/it.json`, `locale/nl.json`), 288 keys each.
- Plural objects preserved for `group.sessionCount`, `sessions.expand` and `time.*` in both languages.
- Plugin manifest titles/descriptions:
  - Italian: **Gruppi liberi**
  - Dutch: **Vrije groepen**
- Ten packaged languages: `en zh ja ko de fr es pt it nl`.

## Verification

- 485/485 unit and contract tests.
- All-dictionary parity covers keys, plural categories, placeholders and non-empty values.
- Community and official isolated A+ remain available; no runtime code changed beyond locale resources.

## Known limits

- `dialog.deleteMoveBody` still has two independent counts and remains a string.
- RTL languages are still pending.
