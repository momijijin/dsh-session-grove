# dsh-session-grove 0.4.0-beta.19

Double-count copy fix and release gate.


## Changed

- Removed the single `dialog.deleteMoveBody` two-count string.
- Delete-group body now renders two independently pluralized lines
  (`group.sessionCount`, new `group.subgroupCount`) plus the static
  `dialog.deleteMoveInstruction`; no UI-side plural selection.
- Added `group.subgroupCount` and `dialog.deleteMoveInstruction` to all 19
  dictionaries (288 keys each).

## Verification

- 493/493 unit and contract tests.
- Release gate now requires `test:locale-pack` and `test:all-locales` in
  addition to unit tests and English A+; recorded in docs/RELEASE.md.
