# dsh-session-grove 0.4.0-beta.15

Russian and Hindi language support.

## Added

- Complete Russian dictionary (`locale/ru.json`) with `one/few/many/other`
  plural categories and Russian manifest title/description.
- Complete Hindi dictionary (`locale/hi.json`) with `one/other` plural objects
  and Hindi manifest title/description.
- Both resources are registered through the split i18n registry added in
  `0.4.0-beta.14`.

## Verification

- 490/490 unit and contract tests, including real `Intl.PluralRules('ru')`
  selection (`2 сессии`, `5 сессий`) and Hindi selection.
- English A+ and the Japanese language-pack fixture remain the runtime gates;
  Russian/Hindi are unit-tested resources only, as recorded in TEST-MATRIX.

## Review notes

- Hindi text is roughly 87% longer than English; narrow-sidebar visual checks
  are still pending.
- Russian plural `other` uses the genitive singular for fractional counts.
- No RTL changes; Arabic remains a separate phase.
